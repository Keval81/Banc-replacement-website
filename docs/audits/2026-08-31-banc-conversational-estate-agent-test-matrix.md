# Banc conversational estate agent: behavior-to-test matrix

This matrix records the replacement regression coverage retained when the
superseded scripted property-chat orchestration is removed.

| Acceptance behavior | Replacement proof |
| --- | --- |
| Exact and minimum bedrooms, including current-message bedroom language overriding a conflicting plan | `explicit bedroom language overrides a conflicting model mutation` and `at least four bedrooms sets a minimum and clears an exact maximum` — `lib/__tests__/banc-conversation-state-reducer.test.ts` |
| Potters Bar to Cuffley replacement preserves the active search fields | `handles Potters Bar to Cuffley as a successful location replacement` — `lib/__tests__/banc-conversation-handler.test.ts` |
| Price, feature, type, tenure, department, reset, and unchanged-state refinements remain canonical | `preserves exact and minimum bedrooms across price, location, department, feature and type refinements` — `lib/__tests__/banc-conversation-handler.test.ts`; `switching to lettings derives valid statuses and resets price semantics`, `clear operations use canonical empty and default values`, and `an empty refinement preserves results while still returning fresh state and arrays` — `lib/__tests__/banc-conversation-state-reducer.test.ts`; `resets search state and returns trusted Call and WhatsApp handoffs` — `lib/__tests__/banc-conversation-handler.test.ts` |
| Active-property authorization and server-grounded fact comparisons | `re-authorizes active browser ids through the portfolio and rejects missing live facts` — `lib/__tests__/banc-conversation-tools.test.ts`; `returns one server-grounded comparison covering both authorized properties` — `lib/__tests__/banc-conversation-handler.test.ts` |
| Canonical property card/detail links and unchanged-card suppression | `does not derive links from model prose and preserves trusted property card navigation` — `lib/__tests__/property-chat-ui.test.ts`; `suppresses unchanged cards while retaining a successful search response` — `lib/__tests__/banc-conversation-handler.test.ts` |
| Approved Banc content and an explicit missing-source outcome | `answers Banc content questions with only trusted sources` — `lib/__tests__/banc-conversation-handler.test.ts`; `returns no approved source for unsupported facts` — `lib/__tests__/banc-knowledge.test.ts` |

| Bounded UI history and single-flight submission | `serializes the latest 20 prose messages with the current in-memory context`, `same-tick submissions run one chat turn while a request is in flight`, and `the single-flight runner releases its lock after a rejected chat turn` — `lib/__tests__/property-chat-submit.test.ts` |
| Modal focus lifecycle and safe diagnostics | `traps modal focus and restores the opener and environment on cleanup` — `lib/__tests__/modal-focus-lifecycle.test.ts`; `distinguishes property and knowledge failures and emits only approved diagnostics` — `lib/__tests__/banc-conversation-handler.test.ts` |
